Survival Station — Quick Start

Works with no internet. You cannot break it by clicking.

  1. Turn the computer on with the power button. Wait a minute and sign in as usual.
  2. On the desktop, double-click 🏕 Survival Station — START HERE.
  3. Wait for the calm “Starting…” screen. The big main screen opens by itself.
  4. Click a big button for what you need: Assistant, Encyclopedia, Medical, Food, Maps, Library, Repair.
  5. To ask the Assistant: click 🗣️ Ask the Survival Assistant, type your question, press Enter, and wait.
  6. To go back: click the ← back arrow at the top-left of the window.
⚠️ Safety: For food, plants, or medical choices, never trust one source or the AI alone. Check the guides too. When unsure, don’t.
🔄 If something seems stuck: restart the computer (Start → power → Restart), then double-click START HERE again.
Need more help? Open ❓ How to use this computer on the main screen.
